# AGENTS.md

## Project overview
Web Component Library (WCL) — a Lazarus/pas2js RAD widgetset that compiles Object Pascal to JavaScript. Units live in `widgets/` (runtime, compiled to JS). Design-time registration lives in `design/` (native code for the Lazarus IDE).

## Key files
- `widgets/pas2js_widget.inc` — included at the top of every unit; sets `{$mode delphi}` and `{$modeswitch externalclass}`
- `widgets/wcl.lpk` — runtime package definition
- `design/package/wcldsgn.lpk` — IDE design-time package
- `widgets/controls.pas` — base classes (2769 lines, `TCustomControl`, `TControl`, etc.)

## Compilation & toolchain
- Compiler: **pas2js** (2.0+). No CLI build scripts, no tests, no CI in this repo.
- Build is done from the Lazarus IDE via the `.lpk` packages.
- Compiler options from `wcl.lpk`: `-dPas2js -O- -Jc`
- The runtime package depends on `pas2js_rtl`; the design package depends on `IDEIntf`, `LCL`, `FCL`.

## Pascal source conventions
- **Inline JavaScript**: Use `asm ... end;` blocks. Inside, refer to Pascal fields as `this.FFieldName` (standard pas2js convention).
- **Suppressing hints**: Wrap blocks with `{$push}{$hints off}...{$pop}`.
- **Types**: `boolean` (JS native boolean), `String` (Pascal alias for JS string), `Integer` / `Double` for numbers.
- **Web API**: Imported from the `Web` and `JS` units (pas2js RTL). Key types: `TJSHTMLElement`, `TJSMouseEvent`, `TJSTouchEvent`, etc.
- **MIT license header** on every `.pas` file.

## File naming notes
- `widgets/` contains some backup/WIP variants: `*.pas_` files and `datagrid_ok.pas`, `datagrid_OK1.pas`, etc. The canonical working file for extctrls is `widgets/extctrls.pas` (not `extctrls_NO.pas`).
- `widgets/wcl.pas` is auto-generated by Lazarus — do not edit.

## Component conventions
- Follow LCL naming: `TCustomXxx` for base classes, `TXxx` for publishable ones.
- Properties use getter/setter methods (e.g. `procedure SetZoomLevel(AValue: Integer)`).
- The `Changed` method (calls `inherited Changed`) is the central point for applying CSS styles to the handle element.
- Always guard style changes with `if (not IsUpdating) and not (csLoading in ComponentState)` inside `Changed`.
